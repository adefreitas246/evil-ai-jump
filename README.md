## Project: Simple Jumping Game

A web-based, side-scrolling jumping game inspired by Google Chrome's offline T-Rex game, built using **HTML, CSS, and plain JavaScript**. The game challenges players to jump over incoming obstacles to rack up a high score.

### Core Features
*   **Player Physics:** Keyboard-controlled jumping mechanics (Spacebar) paired with simple physics simulation for gravity.
*   **Dynamic Obstacles:** Automated obstacle generation that spawns threats at regular intervals and moves them across the screen.
*   **Collision Detection:** Real-time crash detection that immediately stops the game and triggers a "Game Over" state when an obstacle is hit.
*   **Live Scoring System:** Keeps track of successfully cleared obstacles and displays the player's current score on-screen.

### Upcoming & Optional Goals
*   **Increased Difficulty:** Randomized obstacle heights and positions to keep gameplay unpredictable.
*   **Multimedia Integration:** Immersive background music and audio effects for jumping and crashing.
